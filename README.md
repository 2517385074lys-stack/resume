# resume — Markdown 简历编辑器

一个单文件的纯前端简历编辑器（`freecv-enhanced.html`），支持可视化编辑与 Markdown 源码双模式，实时预览 A4 分页效果，可导出 Markdown / PDF / Word。无需安装、无需构建，浏览器打开即用。

## 主要功能

- **双模式编辑**：「可视化编辑」以模块化卡片操作简历内容，「Markdown 源码」直接编辑源文本，两种模式实时双向同步。
- **格式化工具栏**：标题（H1–H3）、粗体/斜体/删除线、有序/无序列表、引用、链接、分隔线、行内代码、代码块、表格，以及字号、字体、文字颜色设置；支持 Ctrl+B / Ctrl+I / Ctrl+Z / Ctrl+Y 等快捷键。
- **模块化管理**：内置教育背景、专业技能、工作经历、项目经历、获奖证书、自我评价等常用模块，可添加自定义模块，支持上移/下移和拖拽排序。
- **实时 A4 分页预览**：右侧按 A4 纸尺寸（794×1123px）分页渲染，所见即所得。
- **多套模板与排版调整**：5 套模板（深色专业风、现代清新风、商务稳重风、活力创意风、简洁学术风），可自定义主题色、字体、行距，整体字号 70%–130% 缩放。
- **智能一页**：一键自动调整字号与行距，将内容压缩到一页 A4 内。
- **照片支持**：上传证件照（JPEG/PNG/WebP），可在页面上拖动调整位置和缩放。
- **导入/导出**：导入 `.md` 文件；导出 Markdown 文件、PDF（通过浏览器打印）、Word 文档。
- **本地保存**：内容自动保存到浏览器 localStorage，也可手动保存/加载，关闭页面后数据不丢失。

## 使用说明

本项目为单 HTML 文件应用，无任何外部依赖：

1. 下载或克隆本仓库；
2. 直接用浏览器打开 `freecv-enhanced.html` 即可开始编辑；
3. `示例简历.md` 是 Markdown 格式的简历示例，可通过「导入MD」按钮载入体验。

> 注意：数据保存在浏览器 localStorage 中，清理浏览器数据会导致内容丢失，重要内容请及时导出。
